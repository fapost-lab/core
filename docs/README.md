# Documentation

This directory is the repository documentation home for FaPost Core.

Use [INDEX.md](./INDEX.md) for the complete map. The short version:

- [platform](./platform) — build and maintain the Core platform.
- [developers](./developers/index.html) — HTML portal for future Features, Solutions, Plugins, flow nodes, and builder
  extensions.
- [reference](./reference) — detailed specs, diagrams, node contracts, and schema references.
- [archive](./archive) — historical material, not the current source of truth.

## Source Of Truth

- `docs/platform/TASKS.md` is the implementation status tracker.
- `docs/platform/ROADMAP.md` is the milestone roadmap.
- `docs/platform/current-state.md` is the code reality check.
- `docs/developers/*.html` is the developer-facing extension portal.
- `drafts/CURRENT_TASK.md` is the only remaining draft file and current operational focus.

If a status looks wrong, verify against code first, then update `platform/current-state.md` and `platform/TASKS.md`.
