# 02 — SaaS-оболочка

## Описание

Существует только в облачном деплое. Self-hosted клиент этот слой не видит — работает напрямую с платформой.

---

## Компоненты

| Компонент | Описание |
| --- | --- |
| **tenants** | id, slug, schema_name, status, created_at |
| **plans** | Тарифные планы: название, лимиты, цена |
| **subscriptions** | tenant → plan, статус, даты |
| **tenant_modules** | Какие модули активированы у тенанта |
| **feature_flags** | Бета-доступ, лимиты, эксперименты |
| **invoices** | История платежей |

> ⚠ Stripe исключён — юридически недоступен. Биллинг — внутренний учёт.
>
