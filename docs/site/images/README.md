# Screenshots

Referenced from the user guide. Filenames match the page that uses them, so a
stale image is easy to find when a screen changes.

## Capturing

Take them from a signed-in session at a **1280 px wide viewport** in **light
mode** — the panel theme is designed light, and a consistent width keeps the
pages from looking assembled from different products.

Crop to the content area, not the whole browser: the chrome adds nothing and
dates the image faster than the interface does.

## Naming

`<page>-<screen>.png`, matching the page's path under `using/`:

    admin-overview-dashboard.png
    roles-and-permissions-editor.png
    flow-builder-canvas.png
