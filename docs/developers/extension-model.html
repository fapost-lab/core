Feature, Solution, or Plugin?

Pick the extension type by ownership, deployment model, and frontend needs.

TypeLives InFrontendStatus
FeatureCore repositoryCan ship Core UIPlanned/partial lifecycle
SolutionExternal composer packageRequires build/publish contractPlanned
PluginExternal composer packageNo arbitrary runtime VuePlanned

Decision Rules

Use a Feature when

The capability belongs to the core product surface and should release with Core.

Use a Solution when

The capability is a vertical package such as HR with its own domain behavior.

Use a Plugin when

The extension registers runtime behavior, adapters, handlers, commands, or schedules.
