Solution Development

Composer-based vertical packages

Solutions are external packages for niche product modules such as FAPost HR.

The external Solution lifecycle is planned, not product-complete in Core.

Target Rules

  • A Solution must not live under app/Solutions inside Core.
  • Public contracts belong in packages/fapost-foundation.
  • Dependency-free primitives belong in packages/fapost-support.
  • Frontend components require an explicit build/publish contract.
