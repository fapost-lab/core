Flow Engine

Add or extend Flow nodes

Node handlers are versioned runtime contracts.

Required Rules

  • Resolve handlers by (type, version) from the in-memory registry.
  • Return sourceHandle, not a target node id.
  • Use a new handler version for breaking contract changes.
  • Make handlers safe to retry and protect external side effects with idempotency.
  • Namespace state keys: system.*, flow.*, rag.*, module.*.
