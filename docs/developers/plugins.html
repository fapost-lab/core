Plugin Development

Runtime extensions

Plugins register behavior with Core without assuming frontend rebuilds at runtime.

The complete Plugin lifecycle is planned.

Target Rules

  • Use approved registrar surfaces for handlers, transports, commands, routes, schedules, and migrations.
  • Depend on public contracts, not concrete Core internals.
  • Do not inject arbitrary Vue components into the running builder.
  • Follow migration isolation rules.
